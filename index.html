// Tentang Saya

Sedikit lebih dekat

Saya adalah mahasiswa semester 5 di Universitas Budi Luhur, jurusan Sistem Informasi. Selain fokus di perkuliahan, saya aktif berorganisasi di Himpunan Mahasiswa Sistem Informasi (HIMASI) — mulai dari merancang program kerja hingga mengelola tim.

Di tahun 2025, saya menjabat sebagai Staff Divisi Education, tempat saya banyak meneliti peluang beasiswa dan berkoordinasi dengan Divisi Humas untuk publikasi informasi beasiswa di media sosial HIMASI.

Memasuki 2026, saya dipercaya sebagai Wakil Kepala Divisi Human Resource, mengawasi kinerja staff dan memimpin penyusunan peraturan internal organisasi.

saya tertarik mendalami pengembangan web dan data science / machine learning — menggabungkan logika pemrograman dengan ketertarikan saya dalam mengolah dan memahami data.
Selain dari angka dan kode, ada juga cerita di balik layar — beberapa momen yang saya abadikan sepanjang perjalanan berorganisasi dan berkarya.
